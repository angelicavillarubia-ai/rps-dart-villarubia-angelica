How to Run the Program
- Install the Dart SDK
   Download it from dart.dev

- Clone or download your repository to your computer.
   type this command in New terminal
   git clone https://github.com/<your-username>/r<yourfile-name>.git
  
- Open a terminal in the project folder.**
   In VS Code: go to Terminal > New Terminal

- Run the program using the command:
   dart rock_paper_scissors.dart(depends on your .dart files)

- Play the game
   - Enter Player 1's name, then Player 2's name 
   - Player 1 enters a move (`rock`, `paper`, or `scissors`).
   - The screen will scroll to hide Player 1's move from Player 2.
   - Player 2 enters their move.
   - The result of the round and the current score will be displayed to the screen.
   - Type y to play another round, or n to end the game and see the final score.
